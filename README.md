# Website-Traffic-Analysis-Dashboard

📌 Project Overview
This project analyzes website traffic data to understand user behavior and identify traffic patterns using Microsoft Excel. The dataset was cleaned, analyzed, and transformed into an interactive dashboard that highlights key metrics and trends.
🎯 Objectives
Analyze website traffic events.
Identify top-performing countries and cities.
Discover the most popular artists and tracks.
Create an interactive dashboard for data visualization.
Generate insights to support data-driven decisions.
🛠️ Tools Used
Microsoft Excel
PivotTables
PivotCharts
Data Cleaning
Dashboard Design
📊 Dashboard Features
Event Distribution
Top 10 Countries by Traffic
Top 10 Cities by Traffic
Top 10 Artists
Top 10 Tracks
KPI Summary
📈 Key Insights
Pageview was the most common user event.
The United States generated the highest website traffic.
Jeddah recorded the highest traffic among cities.
Tesher was the most viewed artist.
Jalebi Baby was the most popular track.
💡 Recommendations
Improve data quality by reducing missing values.
Focus marketing efforts on high-traffic regions.
Promote top-performing artists and tracks.
Monitor website traffic regularly through dashboards.
Use insights to improve user engagement.
